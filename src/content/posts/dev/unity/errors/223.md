유니티를 play 해놓은 채 시간이 오래 지나면(1시간 이상. 조작없음.), 갑자기 vscode에서 using GLTFast 를 쓴 모든 곳에서 에러가 났다. 해당 네임스페이스를 못 찾았고, 해당 네임스페이스 속 클래스를 쓴 모든 코드가 빨갛게 변했다. 예전에는 어떻게 고쳤었는지 기억나지 않지만(1번 똑같은 경험이 있었다), 이번에는 이렇게 고쳤고, 저번과 다르게 걸려얻은게 아니라 나름 논리적으로 고친 듯 하다. 

내 PC에 설치된 dotnet.framework 의 version 은 4.8 이고, GLTFast 라는 유니티에서 무언가 할 때 쓰는 라이브러리? 처럼 생긴 아이는 4.7.1 version 에 종속되어 만들어졌다.. 고, GLTFast.csproj 에 적혀있다. 또한, 유니티프로젝트 폴더 내 다른 csproj 들도 모두 4.7.1 이라고 <TargetFrameworkVersion>v4.7.1</TargetFrameworkVersion> 에 쓰여있는 듯 하다. 해서, GLTFast.csproj 파일 내 TargetFrameworkVersion 태그의 값을 4.7.1 에서 4.8 로 바꾸었다. 여기에서 고쳐진게 아닐까. 컴퓨터를 재부팅하니 이제 vscode 에서 에러가 나지 않는다. 

위의 액션을 취하기 전에는 다른 csproj 파일(유니티관련된) 의 태그값을 바꾸거나, Unity Editor 내에 TargetFrameworkVersion 관련 설정이 있나 찾아봤다 - 지만 없었고, 효과가 없었다. 다른 경우지만, Unity 개발 중 Editor 로 vscode 를 쓸 때 자동완성이나 인텔리전스 등이 정상적이지 않다면, 유니티 프로젝트 폴더 내 csproj 파일들의 TargetFrameworkVersion 태그 값들을 모두 '자신의 PC에 설치된 버전으로 바꾸기' 해서 고치기도 한다고 한다.
