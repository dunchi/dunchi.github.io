tmux 세션에 명령을 보냈는데 세션이 아무 반응을 안 한다. 붙여넣기 모드가 켜져 있어서 입력이 삼켜진 것이다.

## 해결

세션을 만든 직후, 그리고 **SSH로 새 호스트에 붙을 때마다** 아래를 실행한다.

```bash
PS1='RDY> '; bind 'set enable-bracketed-paste off' 2>/dev/null
```

## 왜 매번 해야 하나

이건 **로컬 셸 상태**다. hop 할 때마다 새 셸이 뜨니 리셋된다. 서버 설정 파일을 고쳐서 해결하고 싶겠지만, 접속하는 서버가 고정적이지 않다면 그쪽이 더 비싸다.

```
로컬 → pearl → stg          ← hop 2번, 각각 실행
```

프롬프트를 `RDY>` 로 바꾸는 것도 같은 이유다. 기본 프롬프트는 색과 경로가 붙어 있어서 "명령이 끝났는지"를 자동으로 판별하기 어렵다. 단순한 문자열로 바꾸면 오검출이 사라진다.
